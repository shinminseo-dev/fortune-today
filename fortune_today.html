Feature details

페이지별 기능 정의

메인

서비스 콘셉트 소개, 오늘의 문장 바로 뽑기, 고전 선택 진입, 추천 고전, 예약 기능 안내

고전 목록

고전별 핵심 주제와 분위기를 보여주며 사용자가 먼저 책을 고를 수 있는 탐색 페이지

고전 상세

책 소개, 이런 날 추천, 대표 문장 미리보기, 해당 고전만 대상으로 점괘를 뽑는 기능

오늘의 점괘

고전명, 번역 문장, 한문 원문, 오늘의 풀이, 키워드, 다시 뽑기, 복사, 저장 기능

로그인·회원가입

비회원도 점괘는 가능하지만 저장과 예약은 로그인 필요. 가입 시 관심 고전 정보를 받을 수 있음

문장 예약

받을 시간, 요일, 선호 고전, 해석 길이를 설정. 실제 서비스라면 이메일·푸시 알림으로 확장 가능

나의 보관함

저장 문장, 저장 날짜, 풀이 기록, 자주 저장한 고전, 예약 시간을 확인하는 개인 페이지

추가 확장

기분 선택 후 점치기, 친구 공유, 7일 문장 리포트, 고전별 통계, 오늘의 질문 기록 등으로 확장 가능
